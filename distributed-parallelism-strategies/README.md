# Distributed Parallelism Strategies

This folder provides a structured, study-ready summary of distributed parallelism strategies from basic to advanced.

## Contents

- `basic.md`: Fundamental distributed parallelism types.
- `advanced.md`: Advanced and large-scale strategies.
- `selection-guide.md`: Practical selection path and trade-offs.
- `00-consolidated-index.ipynb`: Single entry-point index and run-order notebook.
- `01-basic-distributed-parallelism.ipynb`: Code-first notebook for basic strategies.
- `02-advanced-distributed-parallelism.ipynb`: Code-first notebook for advanced strategies.
- `03-framework-runnable-patterns.ipynb`: Framework-mapped runnable planning notebook.
- `04-distributed-launch-command-builders.ipynb`: End-to-end launch command and config builders.

## Suggested Reading Order

1. Start with `00-consolidated-index.ipynb` for full run order.
2. Read `basic.md`.
3. Read `advanced.md`.
4. Use `selection-guide.md` for implementation planning.
5. Run `01-basic-distributed-parallelism.ipynb` for executable basics.
6. Run `02-advanced-distributed-parallelism.ipynb` for executable planning and templates.
7. Run `03-framework-runnable-patterns.ipynb` for framework launcher mapping.
8. Run `04-distributed-launch-command-builders.ipynb` for command generation templates.
