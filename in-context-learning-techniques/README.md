# In-Context Learning Techniques

This folder provides a structured, study-ready summary of in-context learning (ICL) techniques from basic to advanced.

## Contents

- `basic.md`: Core ICL prompting techniques and practical usage.
- `advanced.md`: Advanced ICL patterns for robust enterprise systems.
- `basic.ipynb`: Runnable notebook for basic ICL techniques with end-to-end evaluation.
- `advanced.ipynb`: Runnable notebook for advanced ICL techniques with strategy comparison.

## Suggested Reading Order

1. Start with `basic.md`.
2. Run `basic.ipynb`.
3. Move to `advanced.md`.
4. Run `advanced.ipynb`.
