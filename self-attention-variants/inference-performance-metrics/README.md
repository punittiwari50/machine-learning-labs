# Inference Performance Metrics

This mini-topic separates inference evaluation into two levels.

## Files

- `basic.md`: core metrics and how to interpret them during serving.
- `advanced.md`: tail behavior, GPU efficiency, and production serving trade-offs.
- `basic.ipynb`: runnable notebook for core inference metrics.
- `advanced.ipynb`: runnable notebook for advanced serving metrics.

## Reading Order

1. Start with `basic.md`.
2. Move to `advanced.md` for serving-scale metrics and optimization.
